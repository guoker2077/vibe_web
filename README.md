# 重要事务 & 闹钟提醒

一个本地运行的重要事务记录/闹钟提醒网站，用于高效、清晰地管理关键任务。

## 功能特性

### 事务管理
- 增删改查事务记录
- 四级优先级（紧急/高/中/低）
- 自定义分类标签
- 截止日期和时间设置
- 关键词搜索和优先级筛选
- 完成标记和批量清除

### 闹钟提醒
- 定时提醒设置
- 重复模式（不重复/每天/每周/每月）
- 开关控制
- 弹窗通知 + 浏览器通知
- 提示音播放

### 界面设计
- 主色调：蓝色 + 白色，紫色点缀
- 渐变顶栏 + 毛玻璃效果
- 统计面板 + 动画过渡
- 响应式布局

## 技术栈

- Vue 3 + Vite
- TDesign Vue Next 组件库
- localStorage 本地数据持久化

## 本地开发

```bash
npm install
npm run dev
```
